# Isla releases

Installers and the update feed for **Isla**, a Dynamic Island for Windows. This repo holds no source code.

## Install

Download `Isla-Setup-<version>.exe` from the [latest release](https://github.com/Kamal142-D/isla-releases/releases/latest) and run it.

## Updates

Isla checks this repo for new versions (Settings › About). Each release carries `latest.json` and a signed update installer that Isla verifies before installing.
